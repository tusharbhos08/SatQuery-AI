# SatQuery-AI

### SIH26167 — Agentic Vision-Language Assistant for Remote-Sensing Image Analysis

SatQuery-AI is a project for analysing satellite and remote-sensing imagery through natural-language queries and specialised image-analysis workflows.

The project brings together a web interface, Python API, machine-learning workflows, and geospatial processing.

## Key Workflows

- Ask questions about remote-sensing images and generate scene descriptions.
- Identify and locate regions of interest in imagery.
- Analyse water bodies, buildings, roads, and vegetation.
- Compare images from different time periods to study changes.
- Explore optical and SAR imagery workflows.
- Generate analysis reports and execution traces.

## Technology

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **ML and image analysis:** Computer vision and geospatial processing workflows
- **Deployment support:** Docker Compose
